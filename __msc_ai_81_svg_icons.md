# Convenient online tool to convert an image that's about 100px wide and height (more an icon) into an SVG

1. SVG Converter by Picsvg
2. Convertio if free quota enough
3. Photopea if you can do tiny bit manual work
4. Inkscape if local app OK

Most convenient fully free online choice: Picsvg.com

Why:
- Upload raster icon
- Pick SVG output
- Few settings only
- Free for occasional use

Best quality free workflow:
1. Upscale icon 4x first if source only ~100px
2. Use Photopea or any cleanup tool to boost contrast/remove background
3. Run through Picsvg
4. Simplify/clean paths after if needed

If you want strongest free result and don’t mind 1 extra step:
- Photopea for cleanup
- then picsvg.com for vectorization
