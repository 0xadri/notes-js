# GPT

## Best Effort Ranking

- GPT-5.6 Sol — strongest verified 5.6 coding tier; best for hardest coding, debugging, system design.
- GPT-5.6 Sol Fast — likely near-Sol quality with speed bias; best tradeoff if Fast mostly changes latency.
- GPT-5.6 Terra — next 5.6 tier; strong coding, below Sol on hardest long-horizon work.
- GPT-5.6 Terra Fast — likely slightly less thorough than Terra, but still above lower families.
- GPT-5.6 Luna — cost/everyday 5.6 tier; good routine coding, weaker on deepest reasoning.
- GPT-5.6 Luna Fast — likely speed-first Luna; still newer family, but less reliable for hard coding.
- GPT-5.5 — stronger than 5.4 on public coding evals; older than 5.6 family.
- GPT-5.5 Fast — 5.5 itself beats 5.4 on coding evals; Fast likely trims depth a bit.
- GPT-5.4 — strong older frontier coding model; still very capable, but behind 5.5/5.6 family.
- GPT-5.4 mini — strongest mini for coding, but mini tier usually below full-size frontier model.
- GPT-5.4 mini Fast — weakest here for complex coding - likely same mini tier with more speed bias.
